# Administração

O módulo de **Administração** concentra as configurações da plataforma.

Acesse pelo ícone de engrenagem no menu lateral.

!!! warning "Permissão necessária"
    O acesso completo à Administração é restrito a usuários com perfil **Administrador**.

---

## Seções deste módulo

- [Usuários](usuarios.md) — gerenciar atendentes e administradores
- [Departamentos](departamentos.md) — organizar a equipe em departamentos
- [Tags](tags.md) — criar tags de conversa e encerramento
- [Canais](canais.md) — conectar WhatsApp, Instagram, Gmail e outros
- [Integrações](integracoes.md) — conectar CRMs e sistemas externos
