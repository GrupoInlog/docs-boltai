# Usuários

**Caminho:** Administração → Usuários

Gerencie os atendentes e administradores que têm acesso à plataforma.

---

## Lista de usuários

A tabela exibe todos os usuários cadastrados com as colunas: Nome, E-mail, Perfil, Departamento, Integração externa e Status (ativo/inativo).

---

## Criar um novo usuário

Clique em **Novo Usuário** e preencha:

| Campo | Descrição |
|---|---|
| **Nome** | Nome completo do usuário *(obrigatório)* |
| **E-mail** | E-mail de acesso *(obrigatório)* |
| **Perfil** | **Admin** (acesso total) ou **Usuário** (acesso de atendente) |
| **Departamento** | Departamento ao qual o usuário pertence |
| **Senha** | Senha de acesso *(obrigatório ao criar)* |
| **Confirmação de senha** | Deve ser idêntica à senha informada |

!!! info "Modos de criação"
    Ao criar um usuário, o modo padrão é **Cadastrar** (cria um novo acesso com senha). Existe também o modo **Adicionar**, para vincular um usuário que já possui conta no sistema de autenticação, sem necessidade de definir senha.

---

## Editar um usuário

Clique sobre a linha do usuário para abrir o formulário de edição. É possível alterar e-mail, perfil, departamento e o status **Ativo/Inativo**.

!!! tip "Desativar vs. excluir"
    Desativar um usuário impede seu acesso à plataforma sem excluí-lo do histórico de atendimentos.
