# Chat

O módulo de Chat é o centro de atendimento da plataforma. Por ele, o atendente recebe, acompanha e responde todas as conversas dos clientes, independentemente do canal de origem (WhatsApp, Instagram, e-mail, etc.).

Acesse pelo ícone de chat no menu lateral.

---

## Seções deste módulo

- [Listagem de Conversas](listagem-conversas.md) — filtros por status, busca e seleção em massa
- [Cadastro de Contatos](cadastro-contatos.md) — criar contatos diretamente pelo chat
- [Envio de Mensagens](envio-mensagens.md) — texto, mídia, templates e notas internas
- [Detalhes do Contato](detalhes-contato.md) — painel lateral com dados da conversa
- [Transferir uma Conversa](transferir-conversa.md) — encaminhar para outro atendente ou departamento
- [Encerrar uma Conversa](encerrar-conversa.md) — finalizar com tags de encerramento
