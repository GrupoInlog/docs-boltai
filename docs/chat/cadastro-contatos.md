# Cadastro de Contatos

É possível criar um novo contato diretamente pelo Chat, sem precisar acessar a área de administração.

---

## Como criar um contato

1. Na barra lateral do Chat, clique no ícone de **Contatos**.
2. Clique no botão **Novo Contato** (ícone de +).
3. Selecione o **tipo de canal** do contato:

    | Canal | Identificador solicitado |
    |---|---|
    | **WhatsApp** | Número de telefone |
    | **E-mail** | Endereço de e-mail |
    | **Instagram** | Usuário (@handle) |
    | **Facebook/Messenger** | ID da página (PSID) |

    !!! info "Canais disponíveis"
        Apenas os canais que já estiverem conectados na plataforma estarão disponíveis para seleção.

4. Preencha o **Nome** do contato (obrigatório).
5. Preencha o **identificador** correspondente ao canal escolhido (obrigatório).
6. Opcionalmente, vincule o contato a uma **Pessoa** já cadastrada no sistema — ou crie uma nova pessoa no momento.
7. Clique em **Salvar**.

Após o cadastro, o contato estará disponível para iniciar uma nova conversa.
