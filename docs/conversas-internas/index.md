# Conversas Internas

O módulo de **Conversas Internas** é um canal de comunicação exclusivo para a equipe interna — atendentes e administradores — sem qualquer visibilidade para os clientes.

Acesse pelo ícone correspondente no menu lateral.

---

## Seções deste módulo

- [Conversa Direta](conversa-direta.md) — troca de mensagens entre dois atendentes
- [Grupos Internos](grupos-internos.md) — comunicação em grupo entre membros da equipe
