# Envio de Mensagens

Com uma conversa aberta, utilize a **barra de entrada de mensagens** na parte inferior da tela para se comunicar com o cliente.

---

## Tipos de mensagem disponíveis

### Texto

Digite a mensagem no campo de texto e pressione **Enter** para enviar (ou **Shift + Enter** para quebrar linha). O campo se expande automaticamente conforme o conteúdo.

### Imagem

Clique no ícone de imagem para selecionar um arquivo do computador. Formatos aceitos: JPEG, PNG, GIF, WebP, BMP, SVG. É possível adicionar uma legenda antes de enviar.

### Vídeo

Clique no ícone de vídeo para selecionar um arquivo. Formatos aceitos: MP4, WebM, MOV, AVI, MKV.

### Áudio

Há duas formas de enviar áudio:

- **Arquivo**: clique no ícone de áudio para selecionar um arquivo (MP3, WAV, OGG, M4A).
- **Gravação de voz**: clique no ícone de microfone para gravar diretamente pelo navegador. Durante a gravação, você pode pausar, continuar, cancelar ou enviar. O tempo de gravação é exibido em tempo real.

### Documento

Clique no ícone de documento para enviar arquivos como PDF, DOCX, PPTX, XLSX, CSV, TXT, ZIP ou RAR.

### Templates (modelos prontos)

Para canais que suportam templates (como WhatsApp Meta), clique no ícone de templates ou digite `/modelos` no campo de texto. Será exibida uma lista de modelos pré-aprovados. Após selecionar, preencha as variáveis dinâmicas e envie.

### Nota interna

Notas internas são visíveis apenas para os atendentes da equipe, sem que o cliente veja. Para criar uma nota, digite `/note` seguido do conteúdo, ou clique no ícone de nota. A mensagem será exibida com a marcação **"Nota interna"** na conversa.

---

## Outras funcionalidades da barra de mensagens

- **Emojis**: clique no ícone de emoji para abrir o seletor.
- **Colar imagem**: cole uma imagem diretamente da área de transferência (++ctrl+v++ / ++cmd+v++) para enviá-la.
- **Pré-visualização**: arquivos de mídia são exibidos em prévia antes do envio, com opção de remover.
